## Customer-Churn_prediction
Analyzed IBM Telco dataset (7K+ records) to predict customer churn using Logistic Regression.

## Tech Stack
Python · Pandas · Scikit-learn · Matplotlib

## Highlights
- 82% model accuracy
- EDA: churn by contract type, tenure, and monthly charges
- Feature importance visualization using logistic regression coefficients

## Run
pip install pandas scikit-learn matplotlib
python customer_churn_prediction_analysis.py
